#### &#x20;Comment commencer l'exercice ?&#x20;

1. Créer le formulaire HTML&#x20;
2. Faire valider le code du formulaire HTML par le formateur&#x20;
3. Créer un fichier JS et afficher un console.log('hello') pour s'assurer que le fichier et bien lié avec le HTML&#x20;
4. Créer un événement qui écoute l'envoi (submit) du formulaire et affiche une alert avec le message "Envoyé !"&#x20;
5. Récupérer le premier champ du formulaire et afficher son contenu avec un console.log&#x20;
6. Tester la saisie de l'utilisateur et afficher un message dans une alert en cas d'erreur&#x20;
7. Modifier le rectangle avec la valeur saisie par l'utilisateur&#x20;
8. Répéter pour les opérations 4 à 6 pour tous les champs du formulaire&#x20;



!!! Toujours tester son site avec la console ouverte !!!&#x20;
